PHẦN A - Jobboard Frontend

Patch này chỉ gồm file mới và file cần cập nhật để tích hợp phần A vào code của B.

Cách áp dụng:
1. Giải nén patch vào thư mục CHA chứa job-board-frontend-main gốc, chọn ghi đè file trùng tên.
2. Những file B không nằm trong patch sẽ được giữ nguyên.
3. npm ci
4. Copy-Item .env.example .env (PowerShell)
5. npm run dev

Nếu không muốn chép đè từng file, dùng bản jobboard_frontend_AB_hoan_chinh.zip đã ghép sẵn.
Xem README_A.md để biết đầy đủ 11 nhiệm vụ, đường dẫn và API.
